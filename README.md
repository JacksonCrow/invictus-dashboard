### 🌐 접속 주소 (사령관님 전용 바로가기)
👉 **https://jacksoncrow.github.io/invictus-dashboard/**

### 🔒 보안 인증 안내
* 본 대시보드는 **Zero-Knowledge AES-GCM 256-bit** 군사 보안 알고리즘으로 보호됩니다.
* 사령관님의 총자산, 4대 전선 수량/평단가, 작전 지침 등 모든 핵심 데이터는 서버 상에 완전 암호화되어 저장되며,
* 사령관님께서 **보안 PIN(기본: `7777`)**을 브라우저에 입력하시는 순간에만 사령관님의 스마트폰 메모리에서 실시간 복호화됩니다.
* 제3자나 해커가 소스코드를 보거나 데이터를 가로채도 절대 해독할 수 없습니다.

### 📲 스마트폰 홈 화면에 앱으로 추가하는 법
1. 스마트폰 브라우저(Safari 또는 Chrome)에서 위 주소에 접속합니다.
2. 브라우저 메뉴에서 **[홈 화면에 추가]** (또는 [앱 설치])를 누릅니다.
3. 스마트폰 바탕화면에 진짜 앱처럼 아이콘이 생성되어, 언제든 1초 만에 자산과 수급 현황을 확인하실 수 있습니다.
